# DEMO XUNIT PRUEBAS CON .NET
## INFORMACION GENERAL
- Este proyecto esta compuesto por 2 proyectos principales, el primero llamado "console" y el segundo llamado "test". El proyecto de console es un proyecto de consola de .NET y el de test es un proyecto de libreria.
- El proyecto de console se utiliza como proyecto base para las pruebas con xUnit
- El proyecto de test es basicamente el proyecto que hara uso de la libreria xUnit para todas las pruebas que se realizaran.
